# Chess AI Arena

Một platform cờ vua mini chạy trên trình duyệt, cho phép bạn (quân trắng) đấu với bot đi nước ngẫu nhiên hợp lệ.

## Chạy nhanh

```bash
python3 -m http.server 8000
```

Sau đó mở: <http://localhost:8000>

## Tính năng

- Bàn cờ trực quan với quân cờ Unicode.
- Luật đi cờ hợp lệ nhờ `chess.js`.
- Bot tự động đi nước hợp lệ ngẫu nhiên.
- Nút **Ván mới** để reset ngay.

## Lưu ý

- Bot hiện chưa có engine đánh mạnh (chỉ random move).
- Tốt phong cấp tự động thành Hậu.
